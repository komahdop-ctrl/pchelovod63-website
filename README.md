**Концепция с 13 октября 2026 года:** сайт о живом сообществе пчеловодов: люди, семейные и промышленные пасеки, слёты, фото, видео, воспоминания и собственный практический опыт. Мы не представляем официальные объединения и не создаём конкурирующую копию многолетней библиотеки документов Сергея Трынкина.

## Сборка

Статический сайт с Vite. `vite.config.ts` включает главную страницу, страницы мероприятий, пасек и организаций, каталог статей и все 25 самостоятельных страниц. Команда `npm run build` или `pnpm build`. При сборке страницы должны появиться в `dist/articles/` и `dist/organizations/`.

**Важно:** успешные коммиты в GitHub сами по себе не гарантируют публикацию на домене https://pchelovod63.ru/. Следует проверить GitHub Pages/публикацию, DNS, HTTPS и открытие внутренних ссылок. В этой редакции факт доступности публичного домена не подтверждён.

## Редакционная политика

- Указываем реальных авторов, редакторов, источники и полученные разрешения на изображения.
- Материалы о здоровье пчёл — общие рекомендации, не замена ветеринарной диагностики или регистрационных инструкций препаратов.
- Учитываем региональные различия и сезонность, не обещаем универсальных результатов.
- Замечания опытных пчеловодов принимаем и исправляем с пометкой об изменениях.
- Не выдумываем даты, биографии, результаты опытов или подтверждения проверки.
