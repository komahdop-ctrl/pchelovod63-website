# ПЧЕЛОВОД 63 — первая рабочая версия

Отдельный React/Vite/TypeScript/Tailwind проект по **утверждённому** светлому дизайн-макету.

## Уже реализовано

- Главная с тёплым оформлением, восемью карточками разделов, анонсом «Дружба 2026», карточками медиаматериалов, баннером и подвалом.
- Отдельная страница `/events/druzhba-2026`.
- Страницы-заглушки будущих разделов.
- Мобильная адаптация.
- Гостевой мини-чат (frontend + Cloudflare Worker/Durable Object backend) без обязательной регистрации, с историей последних 50 сообщений и ограничением частоты.
- Серверные администраторские команды удаления сообщений и очистки истории (требуют секретный токен).

## Важно про фотографии

Все файлы в `public/assets` — **временные иллюстрации, вырезанные из утверждённого макета**, а не реальные фотографии встречи. Они используются исключительно для проверки вёрстки. Замените изображения настоящими фото со встречи **после согласия участников**. Оригинал макета — `DESIGN_REFERENCE.png`.

Настоящие аудиотреки и видео не добавлены, так как ещё не предоставлены. На сайте честно показано состояние ожидания материалов.

## Запуск проекта локально

```bash
npm install
npm run dev
```

Открыть ссылку, указанную Vite (обычно http://localhost:5173).

Проверка сборки:

```bash
npm run build
```

## Подключение бесплатного чата

Чат работает **только после развёртывания Worker**. Пока `VITE_CHAT_WS_URL` не задан, виджет честно пишет, что сервер не подключён. Никакие фиктивные сообщения не публикуются.

1. Проверьте бесплатные квоты Workers и Durable Objects в вашем Cloudflare-аккаунте, без перехода на платные тарифы.
2. Авторизуйтесь через `npx wrangler login`.
3. В `wrangler.jsonc` замените `ALLOWED_ORIGINS` на фактический адрес сайта; для тестов можно задать несколько адресов через запятую.
4. Задайте **секрет** администратора Worker: `npx wrangler secret put CHAT_ADMIN_TOKEN --config wrangler.jsonc`. Не пишите токен в исходниках и `.env`.
5. Выполните `npm run worker:deploy` только после проверки настроек Cloudflare.
6. Создайте `.env.local` по образцу `.env.example` и укажите адрес `VITE_CHAT_WS_URL=wss://имя-поддомена.workers.dev/chat`.
7. Запустите `npm run dev`, откройте сайт в двух браузерах, проверьте общение.

Лимиты сервиса зависят от Cloudflare и могут меняться; при бесплатном тарифе сверх лимита сервис может отвечать ошибкой. Конкретные лимиты и отсутствие расходов необходимо проверить в аккаунте до развёртывания. **Никакая платная операция из проекта автоматически не выполняется.**

Примеры администрирования через командную строку (не размещать токен в публичных файлах):

```bash
# Удалить конкретное сообщение с id 123
curl -X DELETE -H 'Authorization: Bearer ВАШ_СЕКРЕТ' https://ВАШ_WORKER.workers.dev/admin/messages/123
# Удалить всю историю
curl -X POST -H 'Authorization: Bearer ВАШ_СЕКРЕТ' https://ВАШ_WORKER.workers.dev/admin/clear
```

В первой версии не сделана постоянная блокировка гостей по личности: без авторизации невозможно надёжно отличать одного человека от другого. Для публичного запуска потребуется политика модерации и тестирование на злоупотребления.

## Публикация

Используйте **отдельный GitHub-репозиторий для ПЧЕЛОВОД 63** — не подменяйте существующий репозиторий `hutorok-website`, относящийся к другому сайту.

Статическую сборку `dist/` можно размещать в Cloudflare Pages с командой `npm run build`. Рабочий WebSocket Worker разворачивается отдельно. Для вложенного маршрута `/events/druzhba-2026` настройте SPA fallback, если выбранный хостинг не делает этого автоматически.
