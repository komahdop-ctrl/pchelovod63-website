## Материалы и согласование

Личные данные, фотографии, видео и истории других людей публикуем только после согласования с ними или правообладателями. Не копируем материалы с чужих сайтов без надлежащих прав и разрешений.

Раздел «Законы и документы пчеловода» снят с публичного меню 13.10.2026; вместо него развивается раздел практических статей. Ранние рабочие файлы могут сохраняться в истории проекта, но не являются актуальной редакционной программой.

## Сборка

Статический сайт с Vite. `vite.config.ts` включает главную страницу, страницы мероприятий, пасек и организаций, каталог статей и три отредактированные самостоятельные статьи. Команда `npm run build` или `pnpm build`. При сборке страницы должны появиться в `dist/articles/` и `dist/organizations/`.

**Важно:** успешные коммиты в GitHub сами по себе не гарантируют публикацию на домене https://pchelovod63.ru/. Следует проверить GitHub Pages/публикацию, DNS, HTTPS и открытие внутренних ссылок. В этой редакции факт доступности публичного домена не подтверждён.

## Редакционная политика

- Указываем реальных авторов, редакторов, источники и полученные разрешения на изображения.
- Материалы о здоровье пчёл — общие рекомендации, не замена ветеринарной диагностики или регистрационных инструкций препаратов.
- Учитываем региональные различия и сезонность, не обещаем универсальных результатов.
- Замечания опытных пчеловодов принимаем и исправляем с пометкой об изменениях.
- Не выдумываем даты, биографии, результаты опытов или подтверждения проверки.
