# ПЧЕЛОВОД 63

Сайт неофициального портала пчеловодов Самарской области по утверждённому светлому макету.

## Реализовано

- Адаптивная главная страница по утверждённому desktop/mobile дизайну.
- Отдельная страница `/events/druzhba-2026.html`.
- Галерея из настоящих фотографий встречи с полноэкранным просмотром.
- Видео и четыре аудиозаписи.
- Оптимизированные WebP-копии фотографий; оригиналы в исходной папке не изменяются.
- Мобильная компоновка и доступная клавиатурная навигация галереи.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

Проверка production-сборки:

```bash
pnpm build
```

Готовые файлы появятся в `dist/`.

## Медиафайлы

Скрипт `scripts/process_assets.py` создаёт отдельные оптимизированные копии выбранных фотографий. Он не перезаписывает оригиналы. Исходные материалы должны оставаться в папке `D:\ChatGPT\Мои фото и видео\Дружба 2026`.

Файл `DESIGN_REFERENCE.html` — неизменённая копия утверждённого автономного предпросмотра.
