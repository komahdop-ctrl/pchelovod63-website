## Структура

- `/music/` — каталог, один релиз на песню; варианты внутри релиза.
- `/music/gimn-pchelovodov/` — «Пока гудят над миром пчёлы».
- `/music/druzhba-gudit/` и `/music/u-kostra/` — две ранее опубликованные песни слёта, по два существующих MP3.
- `music/releases.json` — единый источник: ID, название, тема, описание, обложка, варианты, ссылки Suno, текст, дата и статус.
- `scripts/build-music.mjs` генерирует страницы до Vite; Vite автоматически добавляет опубликованные и подготовленные релизы в сборку. Главный анонс подключён при сборке; исходная большая главная не переписывалась.

Для новой песни: добавить объект в JSON и файлы в `public/assets/music/` (или существующий каталог audio), выполнить `npm run build`. ID — латинские буквы, цифры и дефисы. Статусы `draft` не попадают в сборку, `ready-for-review` включены для проверки всей будущей публикации в PR, `published` — для согласованных релизов. Сама ветка предварительного просмотра никогда не выкладывается в production автоматически. Отсутствующие поля — null; неизвестные даты не подменять датой выпуска раздела.

Темы: `bees`, `druzhba`, `community`. Пустые темы и карточки не публикуются. Обложки песен «Дружбы» — существующие фотографии мероприятия, не выдуманные оригинальные обложки. Источник: `events/druzhba-2026.html#media`.

## Гимн и текущий режим

Авторизованная сессия Suno проверена: аккаунт komahdop, доступны редактирование собственных записей и окно Download. Проверены только две разрешённые записи. После выбора MP3 кнопка Unlock & Download остаётся disabled; файлы не скачаны. Другие записи не скачивались, генерации не запускались. Используются две ссылки Suno и ясное пояснение временного режима; ложных audio src нет.

Текст взят со страницы первого варианта и сохранён без изменения строк; заголовки куплетов сохранены как в Suno. Продолжительность 5:35 указана по заданию и интерфейсу Suno, без утверждения о локальной проверке двух MP3. Обложка получена из указанного владельцем файла, оптимизирована в JPEG без изменения изображения. `coverApproval: approved` — владелец отдельно утвердил изображение и поручил публикацию.

Встроенные аудио используют `preload=none`, без autoplay. Обработчик play останавливает остальные audio/video на странице. `controlslist=nodownload` убирает штатную кнопку скачивания в поддерживающих браузерах; это не техническая защита публичного медиа от сохранения. Отдельных ссылок на скачивание нет.
