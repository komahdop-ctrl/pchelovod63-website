# Памятка: создание сайтов с телефона через Codex Cloud

Дата: 18.10.2026. Эта памятка подготавливает подключение, но не создаёт и не публикует среду автоматически.

## Исходные проекты

- «ПЧЕЛОВОД 63»: `komahdop-ctrl/pchelovod63-website`; многостраничный статический Vite, Node 24, pnpm 11, `pnpm-lock.yaml`.
- «Пасека Хуторок»: `komahdop-ctrl/hutorok-website`; React, TypeScript, Vite, Node 22, npm.
- У обоих репозиториев публикация GitHub Pages запускается из `main`; для безопасной работы использовать отдельные ветки и PR.
- Для проверки доступа Codex создать две отдельные облачные среды, по одной на сайт: это упростит установку зависимостей.
- Реальные пароли, данные продаж из закрытого сервиса и Cloudflare для обычной разработки не нужны.

## Действия, требующие личного входа

1. Открыть https://chatgpt.com/codex в браузере под своей учётной записью.
2. Через **Work in > Cloud > Select environment > Create environment** (или **Settings > Codex Cloud > Environments**) создать первую среду.
3. Подключить GitHub к **Codex Cloud** при запросе, разрешив два конкретных репозитория. Подключение GitHub в обычном чате не гарантирует доступа в Codex.
4. Выбрать `komahdop-ctrl/pchelovod63-website`, выполнить создание и вставить промпт ниже.
5. После отчёта о проверке выбрать **Publish**, если всё прошло успешно. Установить доступ **Only me**.
6. Аналогично создать вторую среду для `komahdop-ctrl/hutorok-website`.
7. С телефона открыть Codex и выбрать опубликованную среду. Компьютер может быть выключен.

## Промпт для среды «ПЧЕЛОВОД 63»

Настрой облачную среду Codex Cloud, чтобы я мог развивать сайт «ПЧЕЛОВОД 63» с телефона Android без включённого домашнего компьютера. Репозиторий `komahdop-ctrl/pchelovod63-website`. Изучи README.md, EDITORIAL_RULES.md, package.json, pnpm-lock.yaml, vite.config.ts, GitHub Actions и AGENTS.md, если он уже доступен в выбранной ветке. Сайт многостраничный статический, использует Vite. Не переводить его на другие технологии.

Установи Node.js 24 и pnpm 11, выполни `pnpm install --frozen-lockfile`, `pnpm build`; отдельно проверь `node --check public/chat-widget.js` и `node --check chat-worker/src/index.js`. Убедись, что `dist/index.html` и основные разделы корректно собираются. Настрой пригодные для повторных задач команды установки, сборки, тестирования и запуска preview, если интерфейс позволяет. Разреши доступ к сети только для установки общедоступных зависимостей, не проси никаких токенов и не подключай платные сервисы. Создай приватную настройку **Only me**.

Для любых будущих изменений используй отдельную ветку, предоставляй PR и результаты тестов. Не меняй `main` и не публикуй сайт без моего подтверждения. Не меняй настройки Cloudflare, DNS, GitHub Pages или секреты без отдельного согласования. Если что-то не получается, прямо укажи проблему. Сначала закончи настройку, проверь сборку и дай короткий отчёт на русском; не начинай разработку новых функций, пока среда не опубликована.

## Промпт для среды «Пасека Хуторок»

Подготовь отдельную приватную среду Codex Cloud для `komahdop-ctrl/hutorok-website`. Изучи README.md, AGENTS.md (если он имеется в выбранной ветке), package.json и GitHub Actions. Используй Node.js 22 и npm, выполни `npm install`, `npm run build`, проверь React, TypeScript и Vite. Создай и протестируй повторяемую установку и команду просмотра. Никаких новых функций и платных сервисов. Для изменений всегда создавай новую ветку и PR; не меняй `main` и не выполняй публикацию без моего подтверждения. Установи доступ Only me, не запрашивай секретов. Заверши кратким отчётом на русском и попроси опубликовать готовую среду.

## Проверка после публикации

Запустить первую безопасную задачу с телефона: «Проверь проект, выполни сборку и дай отчёт; ничего не меняй, не коммить и не публикуй». Убедиться, что отчёт содержит результаты команд, а не только обещания.
