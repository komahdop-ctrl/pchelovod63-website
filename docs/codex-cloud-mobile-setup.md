## Создание облачной среды
В браузере или приложении для Windows: **Work in → Cloud → Select environment → Create environment**, либо **Settings → Codex Cloud → Environments → Create environment**. Выберите только репозиторий этого сайта и нажмите **Get started**. При запросе лично авторизуйте GitHub; подключение GitHub к чату само по себе не подтверждает доступ среды.

Попросите Codex установить указанные ниже версии, записать повторяемую установку в **Install script**, а запуск preview и проверку готовности — в **Start skill**. Доступ: **Only me**. Сеть: **Package managers**, без дополнительных доменов и секретов. Не подключать Cloudflare, DNS, платные сервисы и production-данные.

После успешных проверок сохраните настройку и нажмите **Publish**. Дождитесь **Environment published**, затем **Start a new task**. Publish здесь сохраняет среду для новых задач; это не публикация сайта. После изменения настройки используйте Republish и новую задачу.

Официальная инструкция: https://learn.chatgpt.com/docs/environments/cloud-environments

## Правила PR
- Для первого запуска используйте ветку `setup/codex-cloud-mobile-20261018`, где уже есть AGENTS.md; если выбор ветки не предлагается, попросите Codex явно переключиться на неё и подтвердить SHA до работы.
- Для последующих изменений — отдельная новая ветка, проверка сборки, небольшой PR с результатами.
- Не менять `main`, не сливать PR, не включать auto-merge и не запускать deploy workflow без явного подтверждения владельца.
- В обоих проектах push в main запускает GitHub Pages. Существующие deploy workflow также имеют ручной запуск: его не использовать для проверки.
- Проверено 18.10.2026: `main` у обоих репозиториев имеет `protected: false`. AGENTS.md и статус Draft — правила работы, а не технический запрет слияния. Защиту main и обязательные проверки можно включить отдельно; сейчас настройки доступа не менялись.
- Зелёная проверка сборки не подтверждает мобильную вёрстку, работоспособность чата или публикацию на домене.

## Проверка с Android
1. Откройте Codex в телефоне под той же учётной записью и выберите опубликованную среду.
2. Отправьте: «Прочитай AGENTS.md. Покажи имя репозитория, текущую ветку и SHA. Выполни установку и проверки из памятки. Ничего не меняй в исходниках, не коммить, не создавай PR и не публикуй. Дай результаты команд по-русски».
3. Убедитесь, что получены фактические результаты команд. Затем повторите задачу при выключенном домашнем ПК.
4. Для проверки пути изменения → PR попросите создать отдельную тестовую ветку, добавить одну строку в документ, выполнить проверки и открыть Draft PR. Не сливайте тестовый PR.
5. Отдельно проверьте preview на телефоне: главную страницу, меню, внутренние страницы и отсутствие горизонтальной прокрутки. Если preview недоступен, отметьте это ограничение.
