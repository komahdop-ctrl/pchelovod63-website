## Статус
Только план и сравнение предложений. **Миграция, покупки, изменение DNS, регистрация нового аккаунта не выполнялись**. Действующие сайты остаются на прежних площадках. Устаревший встроенный чат «Пчеловод 63» выключен на фронтенде; кнопки ведут в MAX. Ранее сохранённые записи и Worker Cloudflare не удалены.

## Цели
- Один недорогой российский хостинг для преимущественно статических общедоступных сайтов.
- Удобное программное развёртывание: GitHub репозитории -> build -> SSH/SFTP -> российский сервер; не загружать ПД в репозитории и CI.
- Отдельный защищённый российский сервер/контур для приёма анкет «ОПЫЛИТЕЛЬ» только после определения оператора, документов, мер защиты и уведомления РКН.
- **Медицинские документы и сведения несовершеннолетних не помещать в публичный веб-каталог и на общий хостинг без специального анализа**. Рассматривать отдельный закрытый защищённый российский контур, доступ по учётным записям, шифрование, резервное копирование в РФ, документы и правовые основания для специальных категорий.
- Сохранить домены без изменения владельца/регистратора; перенести именно обслуживающие сервера по DNS только после теста.

## План без простоя

1. Подтвердить существующий аккаунт Beget и выяснить тариф, объём, число сайтов, доступную мощность, SSH, ключи и способ безопасного CI/CD; не запрашивать пароли в чате.
2. Уточнить у хостинга фактические российские центры размещения сайта и резервных копий; требования для базы заявок (PHP >= 8.1, mbstring, PDO_SQLite, права на каталог ВНЕ public_html, срок хранения, журналы, разграничение, договор поручения обработки).
3. Открыть тестовый тариф (при согласии владельца) и разместить один статический сайт/тестовый домен; сначала проверить SSL, маршруты страниц, CSS/фото, мобильную версию, кнопки MAX и поисковые индексы.
4. Настроить безопасный ключ SSH для автоматического деплоя GitHub Actions -> Beget (без паролей в коде). Настроить проверки и ограничение доступа к ключу. Не выгружать данные посетителей/медицинские сведения в GitHub или GitHub Actions.
5. Перенести основной «Пчеловод 63», затем Хуторок, VEND DESIGN; проверить домены/редиректы, прежние URL и SEO. Менять DNS последним шагом после теста; сохранять возможность отката.
6. Разобраться с существующими чужими сервисами и логами, при необходимости выключить/удалить старый Worker после определения законной процедуры для ранее сохранённых данных.
7. Для «ОПЫЛИТЕЛЯ» включить реальный сбор только при юридической готовности, проверенном защищённом API, российской базе и тестах.
8. Медицинское досье переносить отдельным проектом/договором/решением о защите после правовой оценки. Не объединять с открытыми сайтами лишь для экономии.
