## Восстановление

Архив pchelovod63-timeweb-prepared-20261114.zip сравнен с текущим репозиторием. Новые страницы и 24 фото форума из main сохранены. Из архива взяты только два исправных MP3 «Мёд на кону»; побайтово совпадают с assets/honey-1.mp3 и assets/honey-2.mp3 оригинального shakuta-rock-ready.zip. Размеры 6170342 / 6046444 байт. SHA256 совпадают с ранее зафиксированными в docs/MUSIC.md.

Причина неисправности production: два прежних файла размером около 786 КБ не распознаются ffprobe. В репозитории теперь хранятся ограниченные по размеру исходные части; сборка восстанавливает MP3 и проверяет длину и SHA256. Все 28 переданных GitHub blob SHA сверены с локальными Git blob SHA. Это исключает незаметное усечение при передаче. В публичную сборку попадают обычные полные MP3 по прежним URL, без зависимости от Suno.

К каждой версии добавлены ссылка скачивания, размер и длительность. Сохранены preload=none и остановка предыдущего плеера. Авторство «Мёд на кону» сохранено по согласованным исходным материалам: идея и первоначальный текст Константина Шакуты, доработка текста с ChatGPT, аранжировка/вокал Suno.
