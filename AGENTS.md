# AGENTS.md — инструкции для Codex Cloud

## Назначение проекта
«ПЧЕЛОВОД 63» — неофициальный информационный портал пчеловодов Самарской области. Сначала читай README.md и EDITORIAL_RULES.md, затем изменяй код.

## Технологии и проверка
- Многостраничный статический сайт на Vite. Не преобразовывай без запроса в React, Next.js или другую архитектуру.
- Ориентируйся на CI: Node.js 24 и pnpm 11. В корне: `pnpm install --frozen-lockfile`, затем `pnpm build`.
- При изменении чата дополнительно проверяй: `node --check public/chat-widget.js` и `node --check chat-worker/src/index.js`.
- Страницы, попадающие в сборку, задаются `vite.config.ts`. Не публикуй черновики материалов случайно.
- Проверяй относительные ссылки и корректность на телефонах.

## Безопасность и публикация
- Работай в отдельной ветке, предлагай Pull Request с кратким описанием и результатами проверки.
- Никаких прямых изменений `main`, слияния PR или публикации без явного разрешения владельца. Push в `main` запускает GitHub Pages.
- Не меняй GitHub Actions, домен, DNS, Cloudflare, Wrangler, токены, секреты, окружения и доступы без отдельного согласования.
- Не создавай и не сохраняй реальные пароли, ключи, личные контакты и закрытые данные в репозитории.
- Не заявляй, что сайт доступен по публичному домену, пока это отдельно не проверено.
- Изменения делай небольшими; не переписывай крупные файлы без необходимости.

## Редакционные правила
- Для статей и ответов по пчеловодству соблюдай EDITORIAL_RULES.md.
- В конце каждой публикуемой статьи должен быть раздел «Источники и литература» с фактически проверенными ссылками и точными библиографическими сведениями. Не выдумывай цитаты и проверку книг.
- Не публикуй личные сведения, фотографии и истории третьих лиц без согласования.
- Перед переводом статьи из черновиков в опубликованные запроси подтверждение.
- Если шаг не удалось выполнить, так и сообщи; не называй непроверенное проверенным.

## Формат отчёта владельцу
По-русски, кратко: что изменил, какие команды запускал, что прошло/не прошло, ссылка на PR, что нужно подтвердить. Интерфейс и содержание страниц — на русском.
